| Threat ID | Category               | Component                                        | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                                                                                                                       |

| T-02-15   | Information Disclosure | Snapshot leakage of internal Address fields      | mitigate    | Snapshot maps exactly 8 named fields (no spread). `id`, `userId`, `createdAt`, `updatedAt`, `isDefault` are never copied into `shippingAddressSnapshot`.                                                                                                                                                                                                                              |
| T-02-16   | Tampering              | Order number collision under concurrent creation | mitigate    | `ORD-${Date.now()}-${nanoid(6)}` per D-06. nanoid(6) provides 21 URL-safe-character alphabet → 64^6 ≈ 6.87×10^10 combinations per millisecond — collision probability negligible at portfolio scale.                                                                                                                                                                                  |
